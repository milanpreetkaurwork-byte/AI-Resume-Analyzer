# 🤖 AI Resume Analyzer & Job Recommendation System

### IBM SkillsBuild AI Internship Project

An AI/NLP-based Resume Analyzer that extracts skills from a resume, matches them with suitable job roles, identifies skill gaps, and recommends the most relevant career opportunities.

## 📌 Project Overview

The AI Resume Analyzer uses Natural Language Processing (NLP), TF-IDF, and Cosine Similarity to analyze resume content and recommend suitable job roles based on the candidate's skills.

The system can:

- 📄 Upload and analyze a resume
- 🔍 Extract relevant skills automatically
- 🎯 Match resume skills with job requirements
- 📊 Calculate job match scores
- 🧠 Calculate NLP-based resume-job similarity
- ⭐ Generate a final AI recommendation score
- 💼 Recommend suitable job roles
- 📈 Visualize job matching results
- 📚 Identify skills that can be improved

1. Install required NLP libraries

## 🧠 AI Methodology

### Skill Matching

The system compares skills detected in the resume with the required skills for different job roles.

### TF-IDF

TF-IDF is used to convert resume and job-description text into numerical vectors.

### Cosine Similarity

Cosine similarity measures the similarity between the resume and job-role text.

### Final AI Score

The final recommendation combines skill matching and NLP similarity to rank suitable job roles.
